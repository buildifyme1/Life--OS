لازم نوصّل المشروع بـ Supabase

عشان النظام يبقى حقيقي (تسجيل دخول حقيقي + تخزين سحابي + مزامنة فورية بين أي جهاز)، لازم تعمل مشروع Supabase مجاني وتحط بياناته هنا.

  1. اعمل حساب/مشروع على supabase.com (مجاني).
  2. من Project Settings → API، انسخ Project URL و anon public key.
  3. افتح SQL Editor في Supabase وشغّل محتوى ملف life-os-schema.sql اللي معاك.
  4. حط القيمتين تحت وسيب الباقي علينا 👇
